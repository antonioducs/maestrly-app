Derived material included in Maestrly:

1. The openui-lang language core in src/renderer/genui/lang/, adapted from
   packages/lang-core/src at the pinned commit: tokens, lexer, expression
   parser, statement splitter, AST, materialization and schema validation,
   built-in functions and action steps, evaluator, library definition, Zod
   signature introspection, and the system prompt sections.
2. The element error boundary in src/renderer/genui/runtime.tsx, adapted from
   packages/react-lang/src/Renderer.tsx at the pinned commit.
3. Unit tests in test/unit/genui-lang-*.test.ts, adapted from the lang-core
   tests at the pinned commit.

Maestrly modifications:

- Removed Query and Mutation statements, the @Run step, tool providers and MCP
  data fetching, custom library actions, library extension, OpenUI Cloud
  configuration, edit and inline prompt modes, the incremental streaming
  parser, and all install and runtime telemetry.
- Hardened evaluation for model-written programs: fields are read only as own
  data properties (never __proto__, constructor or prototype), objects are
  built without prototype assignment, concatenation and equality never convert
  objects, action plans and bindings are trusted only when the evaluator made
  them, a prop that fails evaluates to null, and parsing and rendering stop at
  a step budget.
- Each component must own its props schema; sharing one is an error instead
  of silently renaming it.
- Replaced the React runtime (react-lang) with Maestrly's own: program state
  is the declared defaults plus the person's changes, available on the first
  render, and actions are limited to sending a message, opening an http(s)
  URL, and setting or resetting state.
