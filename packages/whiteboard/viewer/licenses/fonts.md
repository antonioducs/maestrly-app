# Fonts bundled with the whiteboard viewer

The `fonts/` directory of the viewer is copied unmodified from the npm package
`@excalidraw/excalidraw` 0.18.1 (`dist/prod/fonts`). That package carries no
license files for them; each family keeps the license of its upstream project.
